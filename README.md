# Car Game – Python Turtle Challenge

**A simple car game built with Python's Turtle graphics.**

---

## 📖 Story

When I was first learning Python, my teacher gave me a challenge:  
*"Here's a picture of a street. Can you recreate it with Turtle?"*

I went home and built it.  
The original code was messy (full of `t1`, `t2`, `t3` and repetition).  
Years later, I rewrote it — cleaner, with functions, lists, and better structure.

This project reminds me of the early days. No skills, just passion.

---

## 🎮 How to Play

- **Arrow Keys** → Move the car (up, down, left, right)  
- **P Key** → Park (teleport car back to start)  

The road has two lanes with white/yellow decorative blocks on both sides.

---

## 🛠️ Tech Stack

- Python 3  
- Turtle Graphics (built-in, no external libraries)
